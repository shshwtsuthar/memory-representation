# v0.1 Workshop Submission

Expected tag: `v0.1-workshop-submission`

## Purpose

This release prepares the repository as a research artifact for "Memory as a Map: Prior-Trajectory Representations for Software Engineering Agents." It documents the code, processed artifact locations, reproducibility boundaries, and release validation checks for the workshop submission.

## Included code

- ContextBench/SWEContextBench conversion, stripping, rendering, and execution helpers under `scripts/contextbench/` and `scripts/run_openhands_contextbench.py`.
- Nebius OpenHands->ADP conversion and validation helpers under `scripts/nebius-experiment/`.
- Figure-generation code under `figures/`.
- Release documentation and validation helpers under `docs/` and `scripts/release/`.

## Artifact links

- ContextBench/SWEContextBench processed artifacts: https://huggingface.co/datasets/shshwtsuthar/memory-representation-contextbench-artifacts
- ContextBench/SWEContextBench trace artifacts: https://huggingface.co/datasets/shshwtsuthar/memory-representation-contextbench-traces
- Nebius OpenHands ADP v0.1: https://huggingface.co/datasets/shshwtsuthar/memory-representation-nebius-openhands-adp-v0.1

## Known limitations

- Single OpenHands/Qwen setup.
- No unrelated-prior or length-matched distractor-prior control.
- Mechanism labels are post hoc.
- Retrospective oracle is diagnostic, not deployable.
- Repository-level license remains TODO until the owner chooses a code license.
